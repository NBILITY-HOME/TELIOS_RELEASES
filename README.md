# TELIOS — distribution

Ce dépôt public ne contient **aucun code source** : seulement les archives
publiées et le manifeste que les postes clients interrogent.

- `latest.json` — version courante, adresse de l'archive et empreinte SHA-256
- *Releases* — les archives elles-mêmes

Le code de TELIOS est privé. Un poste client n'a donc aucun jeton GitHub à
détenir pour se mettre à jour.
