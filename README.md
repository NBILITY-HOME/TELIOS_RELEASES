# TELIOS — distribution

Ce dépôt public ne contient **aucun code source** : l'installateur, les
archives publiées et le manifeste que les postes clients interrogent.

- `install.sh` — l'installateur, à télécharger pour une première pose
- `latest.json` — version courante, adresse de l'archive et empreinte SHA-256
- *Releases* — les archives elles-mêmes

## Installer TELIOS

```bash
wget https://github.com/NBILITY-HOME/TELIOS_RELEASES/raw/main/install.sh
bash install.sh
```

L'installateur demande la clé d'accès fournie avec la licence. Les mises à jour
suivantes se font depuis l'application, sans clé et sans terminal.
